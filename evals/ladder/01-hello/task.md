Create `greet.py` in this folder, at the top level:

- `greet(name)` returns `Hello, {name}!`
- Run as `python3 greet.py NAME`, it prints that greeting and exits 0.
- Given no argument it prints `usage: greet.py NAME` to **stderr** and exits **2**.
- Given an empty string as the name it prints `Hello, stranger!` and exits 0.
- A name may contain spaces or non-ASCII characters and must be passed through unchanged.

Create no other files.
